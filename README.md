# Assignment-4
This repository contains introductory C++ and Object-Oriented Programming (OOP) examples extracted and documented from lecture materials. The programs demonstrate important C++ concepts such as structures, classes, constructors, references, dynamic memory allocation, static members, and function overloading.
 Topics Covered
	•	Introduction to C++
	•	Input and Output using cout and cin
	•	Function Overloading
	•	References in C++
	•	Dynamic Memory Allocation (new and delete)
	•	Structures
	•	Classes and Objects
	•	Information Hiding
	•	Constructors
	•	Static Member Variables and Functions

How to Run the Programs
	1.	Install a C++ compiler such as:
	•	GCC
	•	MinGW

	2.	Compile the program:

g++ filename.cpp -o output

	3.	Run the executable:

./output
